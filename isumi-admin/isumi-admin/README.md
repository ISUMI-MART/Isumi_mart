# Admin Portal – Isumi Mart

## Run in VS Code
1. Extract this ZIP file.
2. Open the extracted **isumi-admin** folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite (usually http://localhost:5173).

## Notes
- This is a React + Vite front-end demonstration.
- Sample data is stored in this browser's localStorage.
- No backend, database, real authentication, payment gateway, or live order synchronization is included.
- The public reference website exposes the staff login screens; deeper authenticated dashboard wireframes were not publicly readable. The portal layout and workflows below are a close, independently implemented interpretation of the Isumi Mart grocery storefront and staff entry points.
